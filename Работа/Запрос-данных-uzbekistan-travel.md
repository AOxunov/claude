# Запрос данных у uzbekistan.travel

Черновик обращения для ПМ. Он вычитывает, правит и отправляет.
Текст — полностью на узбекской кириллице (получатель — госорганизация).

Связано: [[Туризм]], [[00-Обо-мне]]

## Зачем

Наполнять `POST /v1/content-places` вручную через форму — долго и ненадёжно.
Официальный портал — источник, которому можно доверять. Просим выгрузку в структурированном виде.

## Что решили в черновике

- **Типы:** все три — `ATTRACTION`, `MOSQUE`, `PHOTO_POINT`.
- **Внутренние UUID не запрашиваем.** У партнёра просим человекочитаемые значения
  (`category` — slug/название, `amenities` — массив названий), маппинг на наши
  `category_id` / `amenity_id` делаем у себя. Иначе им пришлось бы знать нашу БД.
- **`external_id`** — их собственный ID. Нужен для идемпотентной синхронизации:
  повторная выгрузка не создаст дублей.
- **Картинки — URL**, но в письме перечислены 4 альтернативы (архив, файловое API,
  облачный диск), потому что у госпорталов прямых ссылок часто нет.
- **Права на фото** — отдельный пункт. Без явного ответа использовать нельзя.
- **CORS** упомянут явно: текущая форма грузит файлы браузером (`fetch`),
  на TripAdvisor мы уже упирались в CORS. Нужно знать заранее.

## Открытые вопросы к самим себе

- Кто у нас маппит их `category` → наш `category_id`? Нужна таблица соответствий.
- `place_type` для мечетей: у них может не быть такого разделения — тогда фильтруем по категории.
- Если отдадут только один язык — нужен ли машинный перевод или ждём их?

### 3. Майдонлар харитаси

#### 3.1. Асосий майдонлар

| Майдон | Тури | Мажбурий | Изоҳ |
|---|---|---|---|
| `external_id` | сатр | ҳа | Обектнинг **сиздаги** ички идентификатори. Маълумот қайта юборилганда шу ID орқали мослаштирамиз — такрорий ёзувлар пайдо бўлмайди. Ўзгармас бўлиши шарт. |
| `place_type` | enum | ҳа | Обект тури: `ATTRACTION`, `MOSQUE`, `PHOTO_POINT`. |
| `category` | сатр | йўқ | Категория номи ёки slug (масалан: тарихий обида, музей, боғ). Биз ўз справочнигимизга мослаштирамиз. |
| `name.uz` | сатр | ҳа | Обект номи ўзбек тилида. |
| `name.ru` | сатр | йўқ | Рус тилида. Бўлмаса — `null`. |
| `name.en` | сатр | йўқ | Инглиз тилида. Бўлмаса — `null`. |
| `description.*` | матн | `uz` ҳа | Тўлиқ тавсиф, тахминан 300–1500 белги. **Оддий матн**, HTML тегларисиз. |
| `did_you_know.*` | матн | йўқ | Қизиқарли факт — иловада «Биласизми?» блокида чиқади. 1–2 жумла. |
| `updated_at` | сана-вақт | йўқ | Ёзув охирги марта янгиланган вақт (ISO 8601). Такрорий синхронизация учун керак. |

#### 3.2. Жойлашув

| Майдон | Тури | Мажбурий | Изоҳ |
|---|---|---|---|
| `address.uz` | сатр | ҳа | Тўлиқ манзил. |
| `region` | сатр | ҳа | Вилоят номи. Масалан: «Самарқанд вилояти». |
| `district` | сатр | йўқ | Туман ёки шаҳар. |

### 4. Расмларни узатиш вариантлари

#### 4.1. Вариантлар

**А. Тўғридан-тўғри URL — биз учун энг қулай вариант.**
JSON ичида ҳар бир расмга ҳавола. Талаблар:
- HTTPS, авторизациясиз очилади;
- ҳавола **доимий** — вақт ўтиши билан ўзгармайди;
- оригинал ўлчам, камида **1600×1200 px**;
- формат: JPEG, PNG ёки WebP;
- сув белгиси (watermark) бўлмаслиги маъқул;
- илтимос, `Access-Control-Allow-Origin` сарлавҳаси очиқ бўлсин — расмларни браузердан
  тўғридан-тўғри юклаймиз. Агар имкони бўлмаса, биз сервер томонидан юклаймиз,
  лекин буни олдиндан билишимиз керак.

**Б. ZIP архив + манифест.**
Расмлар папкаларда: `{external_id}/01.jpg`. Архив ёнида `manifest.csv` ёки `manifest.json`:
`external_id, file_name, is_main, sort_order, author, license`.

**В. Сизнинг файл API'ингиз.**
Эндпоинт манзили, авторизация усули ва файл идентификаторларини беринг —
биз ўзимиз юклаб оламиз.

**Г. Булутли диск.**
Google Drive / Yandex Disk / S3. Ҳар бир обект учун алоҳида папка + манифест файл.

#### 4.2. Аудио файллар

Агар аудиогид материаллари мавжуд бўлса — улар ҳам шу тўрт вариантдан
исталганида берилиши мумкин.

#### 4.3. Фойдаланиш ҳуқуқи

Бу алоҳида аниқлаштириш талаб қилинадиган масала. Илтимос, кўрсатиб ўтинг:

1. Расмлардан **тижорий** мобил илова ва веб-сайтда фойдаланиш мумкинми?
2. Муаллиф ёки манбани кўрсатиш шартми? Агар шарт бўлса — қандай шаклда?
3. Матнлар (тавсифлар) учун ҳам шу саволлар.
4. Қандайдир чекловлар борми?

### 5. Маълумотларни узатиш усули

| Усул | Тавсиф | Изоҳ |
|---|---|---|
| **А. Бир марталик файл** | Битта JSON файл | Энг тез бошлаш усули |
| **Б. API эндпоинт** | Пагинация билан GET сўров | Узоқ муддат учун афзал |
| **В. Даврий выгрузка** | Ойда бир марта янги файл | Ўртача вариант |
| **Г. Webhook** | Ўзгаришлар ҳақида хабар | Қўшимча, мажбурий эмас |

Агар JSON файл 50 МБ дан ошса — қисмларга бўлиб беринг ёки пагинацияли API таклиф қилинг.

### 6. Қулайликлар справочниги

Бизнинг тизимимизда мавжуд қулайликлар. `amenities[]` майдонида шу номларни ишлатсангиз,
мослаштириш автоматик бўлади.

**ATTRACTION:** Аудиогид · Автотураргоҳ · Бепул Wi-Fi · Чиптахона · Гид хизматлари ·
Ҳожатхона · Кафелар ва фудкорт · Кийим алмаштириш хонаси · Кутиш зали · Маълумот столи ·
Ногиронлар аравачаси учун кириш · Сувенирлар дўкони

**MOSQUE:** Автотураргоҳ · Аёллар учун намозхона · Болалар хонаси · Ҳожатхона ·
Кутубхона · Ногиронлар аравачаси учун кириш · Таҳоратхона

**PHOTO_POINT:** Автотураргоҳ · Кузатув майдончаси · Миллий либослар ижараси ·
Панорамик кўриниш · Профессионал фотограф · Тунги ёритиш

### 7. Умумий техник талаблар

| Параметр | Талаб |
|---|---|
| Кодировка | UTF-8, BOM'сиз |
| Формат | JSON (RFC 8259). Массивлар — массив, объект эмас |
| Координаталар | WGS84, ўнлик даража, ажратувчи — нуқта, 6 хона |
| Сана-вақт | ISO 8601, UTC: `2026-08-01T12:00:00Z` |
| Вақт | `HH:MM`, 24 соатлик |
| Ҳафта куни | 1 = Душанба … 7 = Якшанба |
| Телефон | E.164: `+998XXXXXXXXX` |
| Бўш қиймат | `null` (бўш сатр `""` эмас) |

### 8. Саволлар

1. Юқоридаги форматда маълумот беришингиз мумкинми? Агар йўқ бўлса — сизда мавжуд формат қандай?
2. Жами нечта обект ҳақида маълумот бор? Тахминий сон ҳам етарли.
3. Тавсифлар уч тилда (uz / ru / en) тўлиқ тўлдирилганми, ёки фақат бир тилдами?
4. Ўзбекча матнлар лотин ёзувидами ёки кириллдами?
5. Расмларни 4-бўлимдаги қайси вариант билан бера оласиз?
6. Расмлар ва матнлардан тижорий фойдаланиш ҳуқуқи борми (4.3-бўлим)?
7. Аудиогид аудио файллари мавжудми?
8. Маълумот бир марталик выгрузками, ёки доимий API орқали олиш имкони борми?
9. Агар API бўлса: авторизация тури, пагинация, сўровлар лимити қандай?
10. Маълумотлар қанчалик тез-тез янгиланади?
11. Техник саволлар бўйича кимга мурожаат қилайлик — масъул шахс ва алоқа маълумотлари?
