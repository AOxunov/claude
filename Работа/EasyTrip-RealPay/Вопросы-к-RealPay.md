## Уже выяснено

- Платёж проводит checkout SDK (`api-checkout…/api/merchant/sdk`), а не агентский сервис — 2026-09-21.
- Успешный `code` в ответах RealPay — `0`, не `200` — 2026-09-18.
- Токен агента принимает и merchant-billing — 2026-09-18.
- `kassa-template/v1/create` в агенте возвращает имя шаблона (32 hex), в billing — `true`
  (один шаблон на аккаунт) — 2026-09-18.
- Касса копирует шаблон при создании; API изменения кассы нет — 2026-09-22.
- `kassa_id` в `/info` приходит на верхнем уровне (по документации; в SDK-запросе тоже есть).
- Конструктор: принимает `PUT`, отдаёт GET-параметры как `#имя`, читает вложенные поля
  (`#body.x`, `#additional_data.x`), сам проверяет Basic (без него — 401) — 2026-09-18.
- Callback `check-status` с Basic кассы отвечает корректно в конверте платформы — 2026-09-22.
