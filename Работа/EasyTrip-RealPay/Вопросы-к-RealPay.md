# Вопросы к RealPay и открытые пункты

Контекст: [[00-Обзор]], [[Agent-API-RealPay]], [[Callback-API-RealPay]].
Отмечать галочкой по мере ответов и переносить ответ в нужную заметку.

## К RealPay — блокирующие

- [ ] **Единицы суммы**: сумы или тийины? Касается `amount`, `min_amount`, `max_amount`,
      `total_amount`, `commission_amount`, `transactions_sum`.
- [ ] **Можно ли инициировать оплату со стороны EasyTrip** (ссылка на оплату, инвойс,
      checkout на сайте) или только из мобильного приложения RealPay?
      Что означают типы касс `INVOICE`, `PAYMENT_ON_SPOT`, `REAL_GO`, `WITH_BILLING`,
      `WITHOUT_BILLING` и как тип задаётся при создании?
- [ ] Допустим ли **один `url` на все кассы** агента с уникальными Basic-логином/паролем
      на каждую кассу?
- [ ] Прод-адрес Agent API и порядок выдачи прод-доступа агенту.

## К RealPay — по оплате

- [ ] `payment_type: HOLD` — как подтверждается или снимается холд? Эндпоинта нет.
- [ ] Таймауты и повторы при вызове наших эндпоинтов. Что будет, если `/payment`
      с `SUCCESS` не дошёл или мы ответили ошибкой?
- [ ] Может ли прийти `SUCCESS` после `ERROR` (или наоборот) по одной транзакции?
- [ ] Список IP, с которых RealPay вызывает эндпоинты мерчанта.
- [ ] `/cancel`: может ли мерчант отказать в отмене (отрицательный код)? Бывают ли
      частичные возвраты?
- [ ] `/reconciliation`: фильтровать по времени создания или последнего изменения?
- [ ] Формат `timestamp` в ответах мерчанта — действительно `dd.MM.yyyy HHmmss`?
- [ ] `provider/response/*` — это справочник текстов для наших отрицательных
      `response_code`, которые клиент видит в приложении? Что значит `moderated`?

## К RealPay — фискализация (ОФД)

- [ ] `commission_info` — ИНН/ПИНФЛ турфирмы-комитента при агентской схеме?
- [ ] Какие ИКПУ (MXIK) и коды упаковки использовать для туристических услуг?
      Как считать НДС для турфирм без НДС?
- [ ] Обязателен ли `check-commitent = true` перед `merchant/v1/create`?

## К RealPay — Agent API

- [ ] Время жизни `access_token`. Отзывается ли старый токен при новом `sign-in`?
- [ ] Форматы дат `gov_reg_date`, `id_date`, `id_expiry_date`.
- [ ] Что такое `field_control` в `param_ins`? `param_in_value_list` — варианты для `COMBOBOX`?
- [ ] `kassa-template/v1/create` — откуда берётся имя шаблона (в теле его нет)?
- [ ] Какие коды ошибок, кроме `-8` (нет авторизации), возвращает Agent API? Есть ли список?

## Проверить у себя (конструктор easy-trip)

- [ ] Эндпоинт конструктора умеет принимать `PUT`.
- [ ] Можно читать заголовок `Authorization` (Basic) в коде эндпоинта.
- [ ] Можно вернуть свой JSON без обёртки платформы и всегда HTTP 200.
- [ ] Можно сделать эндпоинт без авторизации платформы.
- [ ] Поддерживаются ли параметры в пути (`…/real-pay/{id}/info`) — нужно, если не
      получится различать кассы по Basic-логину.
- [ ] Где хранить секреты (логин/пароль агента) вне кода эндпоинта.
- [ ] `redis.publicSet` — общее ли пространство ключей между проектами.
