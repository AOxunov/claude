## Что понял

- `js` в конструкторе — голый объект Vue 2: без `import`, CSS не scoped, один корневой элемент в шаблоне.
- `offsetTop` врёт внутри таблиц: `offsetParent` — это ближайшая ячейка `td`. Положение считать через `getBoundingClientRect`.
- `scrollTo({behavior: 'smooth'})` в части окружений молча ничего не делает, а на скрытой вкладке не вызывается `requestAnimationFrame` — нужна своя анимация со страховочным таймером.
- Word не понимает flexbox: двухколоночную часть для DOC надо отдавать таблицей.
- Telegram Desktop создаёт файл нужного размера из одних нулей и дописывает его по ходу загрузки. Два раза пришёл такой пустой файл (`2026_org.docx`, `js.txt`) — перед работой проверять, что внутри есть содержимое.
- Файл коллеги прошёл через кодировку Windows-1251: узбекская `ʻ` и BOM превратились в `?` (`to?lanadi`). Решение: символы вне 1251 записывать в JS как `\u02bb`, `\ufeff` — тогда файл переживёт любую перекодировку.

- Ошибки в `submit` коллеги, не исправлены (его код): при незаполненной форме — `this.focusInput is not a function`; при заполненной — `res is not defined`, а `POST v1/procurement` закомментирован и данные не отправляются; `uploadWordFile()` вызывается до `try`.
- Как называются метки: в файле `{$$date_uz_text}` (date), в вопросе было `{$$data_uz_text}` (data) — сверить со вторым программистом.
- Жирность меток даты в Word: объяснено (`"b": 0` → `"b": 1`), но не внесено.
- Решения, которые стоит подтвердить: должность `(lavozimi)` оставлена полем, хотя в новом шаблоне не зелёная; п. 16 и 16.1 только на узбекском, хотя в новом шаблоне двуязычные.
