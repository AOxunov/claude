# Правила работы в этом vault

Это личный Obsidian vault Муталиба, синхронизируется через git между рабочим и домашним компьютером. Контекст о пользователе — в [00-Обо-мне.md](00-Обо-мне.md).

## В начале сессии

1. Выполнить `git pull` — на другом компьютере могли остаться неподтянутые изменения.
2. Прочитать:
   - [00-Обо-мне.md](00-Обо-мне.md)
   - [Java/00-План.md](Java/00-План.md)
   - последнюю по дате запись из папки `Журнал/`

## В конце сессии

1. Создать `Журнал/ГГГГ-ММ-ДД.md` с разделами: что разобрали, что понял, что осталось непонятным, что делать в следующий раз.
2. Убедиться, что все изменения закоммичены и запушены (см. «По ходу работы»), чтобы на втором компьютере не было конфликтов при следующем `git pull`.

## По ходу работы

- Обновлять [Java/00-План.md](Java/00-План.md) — отмечать пройденные темы и статус.
- Дописывать в [Java/Ошибки.md](Java/Ошибки.md) всё, где пользователь ошибся или путается.
- Новые темы по Java оформлять отдельными файлами в `Java/Заметки/`.
- После изменений: `git add`, `git commit` с осмысленным сообщением, `git push`.
- Объяснять, **почему** код работает так, а не просто выдавать готовый ответ.
- Учитывать: сильная сторона пользователя — проектирование БД, Java он восстанавливает после долгого перерыва. Не считать его новичком в программировании в целом.
